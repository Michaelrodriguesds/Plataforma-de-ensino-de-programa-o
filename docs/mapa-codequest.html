3. O que acontece ao clicar em "Verificar"

O código do aluno roda de verdade. Cada linguagem roda num lugar diferente, mas o resultado é comparado do mesmo jeito.

Código do aluno + código de testeO teste é juntado ao que o aluno escreveu
depende da linguagem
JavaScript, HTML, SQL, React, Node e terminalRodam numa "sala separada" do navegador (Web Worker): SQLite de verdade, um Node e um Git de treino. Laço infinito? A sala fecha em segundos.
PythonPython de verdade dentro do navegador (Pyodide). A 1ª vez baixa ~10 MB.
JavaVai para o servidor: compila, roda por até 5 s com bloqueios de segurança e apaga tudo.
a saída é comparada com a esperada
Igual"Mandou bem!" · o servidor calcula XP e estrelas (ninguém trapaceia no ranking)
Diferente ou erroMostra a linha diferente, traduz o erro para português e libera as dicas
